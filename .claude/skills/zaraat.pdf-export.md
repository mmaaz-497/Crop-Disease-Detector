### Step 3 — Implement lib/pdf.ts

Generate the complete PDF export module. The exported PDF MUST include (per constitution SC-004):

1. **Header**: Zaraat AI logo text in `#1B4332`, tagline
2. **Scan metadata**: Date, scan ID
3. **Disease name**: Bold, large font
4. **Severity badge**: Coloured box — Mild (#74C69D), Moderate (#F59E0B), Severe (#EF4444)
5. **Treatment steps**: Numbered list, each step on its own line
6. **Spray schedule**: Italic, indented
7. **Medicines section**:
   - Brand names (with Pakistani brand labels)
   - Generic chemical names
8. **Footer**: "Generated by Zaraat AI — AI-powered crop disease detection"

Layout requirements:
- A4 page size
- Font size ≥ 11pt for body text (readability for farmers)
- For Urdu PDFs: use `jsPDF` with a Unicode-capable font (embed Noto Naskh Arabic if available, else fall back to Latin transliteration with note)
- For English PDFs: standard Helvetica

Implementation template:

```typescript

import { DiagnosisResult } from '@/types/diagnosis';
```
